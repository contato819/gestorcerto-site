# Logos dos parceiros

Coloque aqui os arquivos **oficiais** das logos dos parceiros (com autorização de uso de cada marca).

## Padrão dos arquivos
- **Formato:** PNG com fundo transparente (preferido) ou SVG. JPG só se não houver outro.
- **Tamanho:** altura ~120px ou mais (quanto maior, melhor — a exibição reduz). SVG não tem tamanho fixo.
- **Proporção:** logo "deitada" (horizontal) funciona melhor nos cards.
- **Nome do arquivo:** minúsculo, sem acento e com hífen, igual ao parceiro. Exemplos:
  - `santander.png`
  - `porto-seguro.png`
  - `c6-bank.png`
  - `banco-bv.png`
  - `canopus.png`
  - `gazin.png`
  - `suhai.png`
  - `mapfre.png`
  - `allianz.png`
  - `banco-inter.png`
  - `amil.png`
  - `alice-saude.png`
  - `bradesco-saude.png`
  - `sulamerica.png`
  - `vr-beneficios.png`
  - `vr-gente.png`
  - `orienter-travel.png`
  - `cativa.png`
  - `banco-cora.png`
  - `open-mei.png`
  - `hubstrom.png`
  - `questor-sistemas.png`

## Depois de colocar os arquivos
Avise que estão aqui. Os monogramas (iniciais) na seção "Parcerias Estratégicas" da home serão
substituídos pelas logos reais, com tamanho/recorte padronizados, e o Admin do Site passa a apontar
para os arquivos.

> Observação: usar a marca de um parceiro normalmente exige o kit de marca / autorização da empresa.
> Garanta que há permissão de uso antes de publicar.
